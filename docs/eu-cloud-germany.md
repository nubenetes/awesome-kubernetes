## German Compliance, Standards and Sovereign Stack

- **(2026)** [BSI C5 Criteria Catalogue (Cloud Computing Compliance Controls)](https://www.bsi.bund.de/EN/Themen/Unternehmen-und-Organisationen/Informationen-und-Empfehlungen/Empfehlungen-nach-Angriffszielen/Cloud-Computing/Kriterienkatalog-C5/kriterienkatalog-c5_node.html) 🌟 - Official German Federal Office for Information Security (BSI) auditing baseline mandatory for German public health, statutory insurance, and regulated enterprise cloud procurement.
- **(2026)** [Sovereign Cloud Stack GitHub Standards](https://github.com/SovereignCloudStack) 🌟 - Open-source engineering repositories and reference implementations (OpenStack, Kubernetes/Gardener/CAPI, Ceph, automated compliance tests) powering Germany's sovereign federated cloud providers.
- **(2026)** [ENX TISAX Automotive Information Security Standard](https://enx.com/en-US/TISAX) 🌟 - Mandatory European automotive supply-chain cybersecurity assessment framework supported by German sovereign cloud operators including Open Telekom Cloud and noris network.
